# RSA 解題程式使用筆記

這份筆記說明如何使用同資料夾的 [solve_rsa.py](solve_rsa.py)。程式有兩種用法：知道 `n` 的質因數時，計算私鑰解密；只知道 `n`、`e`、`C` 且公開指數很小時，嘗試低指數搜尋。兩種方式都只用 Python 標準函式庫。

## 先填題目給的數字

打開 `solve_rsa.py`，修改檔案最上方的「在這裡填入資料」：

```python
n = 題目的模數
e = 題目的公開指數
C = 題目的密文整數
```

`C` 是大寫欄位名稱，請填**十進位整數**，不要把數字加上引號。若題目給的是十六進位，先用 `int(十六進位字串, 16)` 轉換。每次換題目，都要重新核對這三個值。

## 用法一：已知質因數

若已經知道 `n = p × q`，把 `p`、`q` 的 `None` 改成對應的質數，`p_power`、`q_power` 保持 `1`：

```python
p = 題目的第一個質數
p_power = 1
q = 題目的第二個質數
q_power = 1
r = None
r_power = 1
```

如果是三個不同質數相乘，再填 `r`。如果某個質數重複出現，例如 `n = p² × q`，就將 `p_power = 2`。程式會先檢查各因數次方的乘積是否等於 `n`，再計算 `φ(n)`、私鑰 `d` 和明文 `m`。`p`、`q`、`r` 必須是**互不相同的質數**；程式不會替你分解 `n`，也不會替你做質數檢測。資料夾裡的 `質因數分解網站.url` 是查找質因數時可用的捷徑，查到後仍要核對乘積。

## 用法二：沒有質因數，嘗試低指數

若只知道 `n`、`e`、`C`，讓 `p`、`q`、`r` 都保持 `None`。程式會自動進入低指數模式，尋找符合下式的非負整數 `k`：

```text
m^e = C + k × n
```

因為 RSA 加密滿足 `C = m^e mod n`，找到右邊剛好是完整 `e` 次方的值，就能求出 `m`。如果明文夠小，可能直接有 `k = 0`；本題範例需要搜尋更大的 `k`。此模式只支援 `2 <= e <= 17`，且並非所有小指數 RSA 題目都能用這招解開。

`MAX_K = None` 代表不設搜尋上限，可能跑很久；想先試有限範圍，可改成例如 `MAX_K = 50_000_000`。若範圍內無解，程式會提示增加上限或檢查題目條件。要中止搜尋可按 `Ctrl+C`。

## 執行與看結果

在 `PH-writeup` 倉庫根目錄開啟終端機，執行：

```powershell
python "Crypytography 1029/RSA/solve_rsa.py"
```

若你的環境用 `py` 啟動 Python，也可以把指令開頭的 `python` 換成 `py`。程式會印出使用的模式、`m` 和「重新加密驗證：通過」，接著把 `m` 當作大端序整數轉成 bytes，嘗試以 UTF-8 顯示文字。已知質因數模式還會印出 `φ(n)` 和 `d`；低指數模式會印出找到的 `k`。

原檔附的 `n`、`e = 3`、`C`，在保持三個質因數欄位為 `None` 時，實際執行得到：

```text
模式：低指數攻擊
k = 12451936
m = 27318933826220270213125573692554016993661
重新加密驗證：通過
明文文字（UTF-8）= 'PH{E=3_700_sMAl1}'
```

`k` 是搜尋用的整數，旗標是轉成文字後的 `PH{E=3_700_sMAl1}`。換成別題時，輸出會隨填入的資料改變。若出現「明文無法直接以 UTF-8 解碼」，先看 `明文 bytes`，再依題目指定的編碼或填充方式解讀。

## 解題重點

先看題目是否提供或能查出質因數：有的話填 `p`、`q`，直接求私鑰；沒有的話，再看公開指數是否小、明文是否可能短到足以用 `m^e = C + kn` 搜尋。程式最後會用 `pow(m, e, n) == C` 重新加密核對，這能檢查結果與輸入的密文是否一致。
